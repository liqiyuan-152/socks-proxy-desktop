# Socks Proxy v0.2.2

本次更新品牌图标和中文安装体验，并加固 Windows 升级、卸载时的配置保留。

- 原创蓝色盾牌网络图标，适配桌面、任务栏、托盘和浏览器 favicon；macOS 菜单栏使用模板图标。
- Windows 简体中文 NSIS EXE、品牌安装素材和中文第三方组件说明；移除代理开关旁的重复状态标签，避免窄窗口重叠。
- Windows 覆盖安装调用旧 NSIS 卸载器时强制使用 `/UPDATE`，新版卸载器不提供删除应用数据选项，并移除应用数据删除代码。
- macOS 中文 Retina DMG 拖拽引导，提供 Apple Silicon、Intel、Universal 安装包。
- Linux 提供 AppImage、DEB、RPM 和中文桌面元数据。

Windows 安装包使用英文文件名 `Socks-Proxy_v0.2.2_Windows_x64_setup.exe`，安装向导为简体中文。提供七个安装包以及 `SHA256SUMS.txt`、`VERSION.txt`、`SOURCE_REVISION.txt`。请按平台和架构选择安装包，并核对 SHA256；已有 v0.2.1 标签保持不变。

Windows 验收的首次安装曾发生旧应用数据目录被删除，原配置已从完整快照恢复；文件系统日志确认了删除时序，但没有记录当时的具体卸载进程及复选框状态。本版本加固上述安装器数据清理路径，不推断用户曾选择删除数据。升级前建议保留完整备份；配置导出不含认证密码，不能代替完整数据备份。

实际代理运行仅支持 Windows x64；macOS/Linux 支持界面及部分配置管理，不支持代理内核和系统代理接管。安装包未配置开发者签名及 macOS 公证，自动更新尚未启用。

项目许可保持现状。Windows 包含 GPLv3 sing-box 1.14.1 及上游许可证；中文第三方说明不替代原始许可证，也不新增授权或限制。

对应内核源码：[固定提交](https://github.com/SagerNet/sing-box/tree/1ac1a339cb1223e9c70eae14c44411c75033c02d)、[源码归档](https://github.com/SagerNet/sing-box/archive/1ac1a339cb1223e9c70eae14c44411c75033c02d.tar.gz)。内核来源和校验记录见本版本的 `scripts/sing-box-release-manifest.md`。
