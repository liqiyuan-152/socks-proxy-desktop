# Socks Proxy v0.3.2

规则代理支持独立配置国内直连和未匹配流量的默认动作，用户规则优先于国内直连，其余流量按默认动作走代理或直连。状态页提供防抖保存、错误提示和回滚。

## 升级与兼容性

- **破坏性变更**：SQLite 从 v6 迁移为 v7，配置文档从 v2 升级为 v3；IPC 的 Rules 改为带参数对象。
- 启动时事务迁移旧配置和恢复意图，旧 Rules 保留国内直连开关，默认动作设为代理。旧版关闭国内直连时未匹配流量原本直连，升级后改为代理；需要旧行为时，在状态页把“未匹配流量”设置为“直连”。Global／Direct 保持原模式。
- 新建 Rules 默认关闭国内直连、默认走代理。Windows 启动代理模式需要有效的默认代理档案。
- 升级前保留完整应用数据备份。旧程序不能打开 v7 数据库或导入 v3 文档，升级后不能直接降级；配置导出不含认证密码，不能代替完整数据备份。

## 平台与下载

提供 Windows x64 中文 NSIS EXE，macOS Apple Silicon／Intel／Universal DMG，以及 Linux x64 AppImage／DEB／RPM。附件中的 `SHA256SUMS.txt`、`VERSION.txt`、`SOURCE_REVISION.txt` 用于核对校验和、版本和对应源码。

实际代理运行仅支持 Windows x64。macOS／Linux 支持配置管理、模式参数保存和用户规则预测，不启动代理内核或接管系统代理；国内规则集匹配不可用时明确提示。预测结果不代表实际联网成功。macOS 原生配置保存、数据库迁移和预测交互已验收。

此版本为正式 Release。安装包未配置开发者签名及 macOS 公证，自动更新尚未启用。

Windows 包含 GPLv3 sing-box 1.14.1 及上游许可证；项目许可保持现状。对应内核源码：[固定提交](https://github.com/SagerNet/sing-box/tree/1ac1a339cb1223e9c70eae14c44411c75033c02d)、[源码归档](https://github.com/SagerNet/sing-box/archive/1ac1a339cb1223e9c70eae14c44411c75033c02d.tar.gz)。内核来源和校验记录见本版本的 `scripts/sing-box-release-manifest.md`。
