# 品牌图标与安装界面中文化提案

**变更类型**: Enhancement  
**优先级**: P2  
**预计工期**: 3-5 天  
**影响范围**: 品牌标识、安装体验、用户感知

---

## 背景与动机

### 当前问题

1. **缺少品牌识别**
   - 项目使用默认的 Tauri 图标，无品牌辨识度
   - 在任务栏、Dock、桌面显示的是通用图标
   - 缺少专业应用的视觉形象

2. **安装体验不专业**
   - Windows 安装界面使用英文，中国用户体验差
   - 没有自定义的安装向导界面
   - 缺少品牌视觉元素展示

3. **用户信任度低**
   - 通用图标降低应用的专业感
   - 英文安装界面增加使用门槛
   - 第一印象影响用户留存

### 用户影响

- **新用户**: 下载安装时的第一印象不够专业，降低信任度
- **现有用户**: 在多个应用中难以快速识别
- **企业用户**: 缺少品牌形象，不利于内部推广

---

## 目标

### 核心目标

1. **建立品牌识别** - 设计专业、现代、易识别的应用图标
2. **提升安装体验** - 完整的中文安装界面和引导流程
3. **增强专业感** - 通过视觉设计提升产品品质感知

### 非目标

- ❌ 不改变应用核心功能
- ❌ 不进行大规模的 UI 重设计（已有美化计划）
- ❌ 不涉及品牌营销推广策略

## Capabilities

### New Capabilities

- `brand-identity`：跨平台应用图标、菜单栏模板图标和网页图标的统一品牌识别。
- `localized-installers`：Windows、macOS、Linux 的中文安装体验、品牌资源和安装升级兼容性。

### Modified Capabilities

无。现有代理功能和应用数据格式保持兼容。

## 解决方案

### 1. 图标设计策略

#### 推荐方案：盾牌 + 网络节点

**设计理念**：

- **盾牌形状**: 象征安全保护和隐私守护
- **网络节点**: 体现代理转发和网络连接
- **蓝色渐变**: 传达可靠、专业、技术的品牌调性

**视觉元素**：

```
主体：圆润的盾牌轮廓
内容：3-4个互联的圆形节点 + 连线
配色：#4A90E2 → #357ABD（蓝色渐变）
风格：扁平化设计，微妙的渐变和阴影
细节：光滑的圆角，现代感强
```

**适用性**：

- ✅ 在 16x16 到 1024x1024 各尺寸下清晰可辨
- ✅ 深色/浅色背景都能良好显示
- ✅ 符合 macOS/Windows/Linux 设计规范

**技术规格**：

| 平台    | 主要尺寸   | 格式 | 用途             |
| ------- | ---------- | ---- | ---------------- |
| macOS   | 1024x1024  | ICNS | 应用图标、Dock   |
| Windows | 256x256    | ICO  | 任务栏、安装程序 |
| Linux   | 512x512    | PNG  | 桌面环境         |
| 通用    | 32/128/256 | PNG  | 多场景           |

### 2. 安装界面中文化

#### Windows 安装程序（NSIS）

**核心改进**：

1. **语言本地化**
   - 安装向导全中文界面
   - 中文许可协议（RTF 格式）
   - 中文进度提示和错误消息

2. **视觉定制**
   - 自定义 欢迎及完成页侧栏（164x314 px）
   - 品牌顶部图（150x57 px）
   - 产品名称和图标展示

3. **用户体验**
   - 清晰的安装步骤说明
   - "启动应用"复选框
   - 桌面快捷方式选项

**安装包命名**：

```
Socks-Proxy_v{版本}_Windows_x64_setup.exe
```

#### macOS 安装程序（DMG）

**核心改进**：

1. **DMG 背景图**
   - 尺寸：660x400 px（Retina: 1320x800 px）
   - 视觉引导：应用图标 → Applications 文件夹
   - 中文提示："将应用拖拽到 Applications 文件夹"

2. **窗口设置**
   - 合理的窗口大小和图标布局
   - 美观的背景设计
   - 品牌色调统一

**安装包命名**：

```
Socks-Proxy_v{版本}_macOS_Apple-Silicon.dmg
Socks-Proxy_v{版本}_macOS_Intel.dmg
```

#### Linux 安装程序

**核心改进**：

1. **Desktop Entry 中文化**
   - Name、Comment、GenericName 使用中文
   - 正确的图标路径
   - 应用分类和关键词

2. **包元数据**
   - DEB/RPM 包描述中文化
   - AppImage 应用信息本地化

**安装包命名**：

```
Socks-Proxy_v{版本}_Linux_x64.AppImage
socks-proxy_{版本}_amd64.deb
```

### 3. 配色方案

基于现有 UI 设计系统（OKLCH）：

```css
/* 主色调 - 图标渐变 */
渐变 A（推荐）:
  起始色: #4A90E2
  结束色: #357ABD

/* 对应 OKLCH 值 */
--icon-gradient-start: oklch(0.62 0.18 250);
--icon-gradient-end: oklch(0.52 0.20 245);

/* 辅助色 - 安装界面背景 */
浅色: #F5F8FA
深色: #1E293B
```

**深色模式适配**：

- 图标使用透明或白色底色
- 主图形保持品牌色，确保在深色背景可见
- 避免纯黑细节，使用深灰色（#2D3748）

## 影响分析

### 正面影响

✅ **提升品牌认知**

- 专业的图标增强产品辨识度
- 统一的视觉语言建立品牌印象

✅ **改善用户体验**

- 中文安装界面降低使用门槛
- 清晰的安装引导减少困惑

✅ **增强信任度**

- 专业的视觉形象提升产品可信度
- 完整的品牌体验增加用户信心

✅ **利于推广**

- 易识别的图标便于口碑传播
- 专业形象吸引更多用户尝试

### 潜在风险

⚠️ **设计审美风险**

- 图标设计需要多轮迭代才能达到最佳效果
- 不同用户的审美偏好差异

**缓解措施**: 提供多个设计方案，收集用户反馈

⚠️ **多平台兼容性**

- 不同操作系统对图标格式和尺寸要求不同
- 安装程序配置需要逐平台测试

**缓解措施**: 使用 Tauri 官方工具生成，严格测试

⚠️ **维护成本**

- 每次发版需要更新版本号和构建配置
- 安装包文件较大，托管成本增加

**缓解措施**: 自动化构建流程，使用 GitHub Releases

## 替代方案

### 方案 A: 仅更换图标，不修改安装界面

**优点**:

- 工作量小，快速完成
- 技术风险低

**缺点**:

- 用户体验改善有限
- 安装界面仍然不够友好

**决策**: ❌ 不采用，收益不足

### 方案 B: 使用第三方图标库

**优点**:

- 省去设计时间
- 图标质量有保证

**缺点**:

- 缺少独特性和品牌识别
- 可能存在版权问题

**决策**: ❌ 不采用，无法建立品牌

### 方案 C: 完整的品牌设计（推荐）

**优点**:

- 全面提升品牌形象
- 专业的安装体验
- 长期品牌价值

**缺点**:

- 需要一定设计和开发时间

**决策**: ✅ 采用
