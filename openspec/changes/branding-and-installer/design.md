## Context

现有 Tauri 2 应用使用默认图标，Windows 发布 NSIS EXE，macOS 发布 Universal DMG。参见 proposal.md 的动机及 DESIGN_SPEC.md 的视觉规范。用户于 2026-10-05 确认 Windows 仅发布中文 NSIS EXE；许可保留现状并新增中文第三方说明。历史 WiX 配置及许可示例不再适用。

## Goals / Non-Goals

**Goals:** 使用可重建的原创素材，适配当前 Tauri 2，提供三平台中文安装和完整发布校验。

**Non-Goals:** 不修改代理功能、DDD 服务层、应用标识、用户数据路径或现有项目许可，不声明尚未支持的协议处理能力。

## Decisions

1. 原创 SVG 盾牌网络图标采用 #4A90E2→#357ABD 渐变，保留 10% 留白；按尺寸分别采用极简、简化、标准及完整版本。资源放在现有 src-tauri/icons 下，使用官方 Tauri CLI 生成 PNG/ICO/ICNS，打包文件中的小尺寸也必须采用对应版本。比起直接缩放完整图标，此方式保持小尺寸可读性。
2. Windows 保持 NSIS 安装身份和 EXE 格式，配置 SimpChinese，制作 150×57 顶部图和 164×314 侧栏，复用官方模板的升级、快捷方式和启动行为。先验证官方模板，确有缺项才最小扩展，避免复制过期 WiX 模板。
3. 中文 RTF 为许可与第三方说明，不新增许可或限制；明确 UNLICENSED 的现状、sing-box GPLv3、固定版本与对应源码位置，并随包保留上游许可证。不得使用禁止逆向工程或无依据的隐私声明。
4. macOS 保留 Universal 支持，并新增 Apple Silicon 与 Intel DMG，中文背景支持标准和 Retina，保持应用标识和最低系统要求。模板菜单栏图标单独集成，菜单行为保持不变。
5. Linux 新增 AppImage、DEB、RPM 打包与中文桌面及 AppStream 信息。元数据仅描述实际功能和许可；不添加 socks URI 注册。包文件检查与实际桌面安装测试分别记录。
6. 发布矩阵和汇总脚本按平台显式验证产物数量、格式、版本、源码及 SHA256；任何缺包或不匹配均拒绝发布。README 和 CHANGELOG 随实现更新，新版本发布不得覆盖已有 v0.2.1 标签。

## Risks / Trade-offs

- [跨平台安装器差异] → 在真实 Windows、macOS 和 Linux 环境验证安装、升级、卸载、图标及配置保留，静态检查不替代实际验证。
- [模板文本覆盖图片] → 保留系统文字区域，检查欢迎、完成和其他页实际截图。
- [默认 ICO/ICNS 缩放丢失细节] → 使用尺寸适配的图标包并检查内部尺寸及透明度。
- [无签名及部分平台不支持代理核心] → 保留现有发布说明，不因品牌改动扩张功能承诺。
- [许可证翻译误导] → 中文说明不替代上游原始许可证，保留来源及原文。

## Migration Plan

Windows 配置保留加固使用与锁定 CLI 2.11.5 对应的官方 NSIS 模板，按固定源码提交和 SHA256 校验后生成到 target/。仅修改旧 NSIS 卸载调用参数、移除数据删除选项及删除分支；其余官方行为保持不变。模板结构或 CLI 版本变化时拒绝构建，要求重新审查。这是配置保留要求的实现加固，不修改数据格式或路径。

按五阶段提交：图标、安装素材、打包配置、跨平台验收、发布准备。应用标识和数据目录保持稳定；升级前后验证配置一致。回滚通过恢复前一版本安装包和资源配置完成，不改写用户配置或已有发布标签。

## 验收范围更新

2026-10-05 用户确认“mac 和 windows 视觉都正常，linux 不用”：macOS/Windows 视觉验收通过；本次取消 Linux 桌面菜单、系统图标及桌面交互的人工视觉验收，保留 Linux 构建、元数据、DEB 安装和 AppImage 启动验证。该决定不豁免配置保留要求，不代表首次 Windows 升级配置缺失已定因或修复。
