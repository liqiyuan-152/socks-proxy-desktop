## Purpose

确保项目的质量结论可追溯到目标 Windows 平台和确实执行过的测试，通过可复现的干净检出、明确的内核测试前置条件及桌面验收记录支撑后续运行时与配置重构。

## ADDED Requirements

### Requirement: 跨平台干净检出可验证

同一提交在 Windows 与本地开发平台干净检出后 SHALL 满足统一文本格式要求，不依赖开发者全局 Git 设置。质量工作流 MUST 执行格式、静态检查、类型检查、前端测试、Rust 检查与测试以及构建，并明确区分失败和未执行步骤。

#### Scenario: Windows 自动换行环境检出

- **WHEN** Windows 执行器以其默认 Git 环境检出仓库
- **THEN** 受约束文本满足仓库换行符规则，格式检查不会因检出转换而整体失败

### Requirement: 真实内核测试显式执行

要求真实内核的验证任务 MUST 校验测试内核存在且与固定版本及哈希匹配。前置条件缺失时 MUST 将该任务判为失败或明确未执行，不得把提前返回计为真实内核验证成功；纯单元测试 SHALL 可独立运行。

#### Scenario: 内核变量缺失

- **WHEN** CI 运行真实内核测试但未提供有效测试内核
- **THEN** 任务失败并提示缺失条件，不生成真实内核测试通过结论

### Requirement: 跨层与桌面验收证据

系统交付记录 SHALL 将组合测试、真实内核测试和真实 Windows 桌面验收分别记录，关联源码提交与测试环境。运行时一致性变更 MUST 覆盖仅替换凭据、切换失败后旧内核退出、慢控制请求和迁移中断。安装包验收 SHALL 包含启动、托盘退出及异常退出恢复；缺少桌面环境时不得标记该验收完成。

#### Scenario: 本地测试全部通过

- **WHEN** 本地单元测试通过但尚未执行 Windows 桌面验收
- **THEN** 记录仅声明已执行部分通过，并保留 Windows 桌面验收待完成状态
