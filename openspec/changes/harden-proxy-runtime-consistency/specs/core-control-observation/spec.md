## Purpose

为桌面代理提供遵循 HTTP 协议且资源使用有界的本地控制请求，并把会话健康、操作失败和观测降级准确反馈给用户，避免慢响应或失效响应干扰模式切换及网络恢复。

## ADDED Requirements

### Requirement: 有界且受保护的控制请求

系统 MUST 仅向当前会话的回环控制端点发送控制请求，使用该会话的独立密钥且绕过环境及系统代理。系统 SHALL 正确处理标准 HTTP 响应分帧，包括分块传输；单次请求总时限 MUST 不超过 2 秒，解码后的响应体 MUST 不超过 1 MiB，超时、超限、认证失败或无效 JSON SHALL 返回可区分的脱敏错误。

#### Scenario: 分块活跃连接响应

- **WHEN** 内核返回分块编码的有效活跃连接 JSON
- **THEN** 系统正确解码并显示脱敏观测，不因 HTTP 分帧将其误报为无效 JSON

#### Scenario: 持续慢速响应

- **WHEN** 内核持续少量发送数据且完整响应未在总时限内到达
- **THEN** 请求在总时限内终止并将观测标记为降级，不无限延长等待

#### Scenario: 超限或未授权响应

- **WHEN** 控制响应超出大小限制或认证被拒绝
- **THEN** 系统终止读取并报告相应错误，日志和界面均不包含认证头或控制密钥

### Requirement: 观测不阻塞会话管理

系统 MUST 允许慢控制请求期间处理模式切换、停止和恢复；旧会话请求的迟到结果 MUST 不覆盖新会话的观测。观测不可用 SHALL 不被推断为连接失败或代理进程退出。

#### Scenario: 读取期间切换内核

- **WHEN** 旧会话控制请求尚未完成而用户启动新模式
- **THEN** 模式操作不等待该请求持有的会话管理锁，旧会话结果返回后被丢弃

### Requirement: 可解释的错误与恢复反馈

系统 SHALL 在状态界面展示当前已应用模式、会话健康、最近操作结果及可公开的错误原因，并提供适用的重试或恢复入口。操作失败且后续快照读取成功时 MUST 不丢失原操作错误；具体错误 MUST 不包含密码、控制密钥或敏感内部路径。

#### Scenario: 切换失败但旧模式有效

- **WHEN** 新模式未成功提交但旧会话仍健康
- **THEN** 页面同时说明切换失败原因和仍生效的旧模式，并允许重试

#### Scenario: 恢复归属不明

- **WHEN** 系统代理设置已被外部修改而无法确认归属
- **THEN** 页面显示恢复未完成及人工检查提示，不仅显示笼统的异常标签
