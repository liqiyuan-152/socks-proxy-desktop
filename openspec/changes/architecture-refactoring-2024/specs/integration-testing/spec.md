## Purpose

建立关键用户场景的可重复验证契约，使测试覆盖配置、运行时、凭据和恢复的组合行为，同时区分模拟依赖的证据与真实 Windows 内核、系统代理和原生界面证据。

## ADDED Requirements

### Requirement: 独立场景验证

测试 MUST 使用独立数据与资源，覆盖代理生命周期、模式切换、凭据修改、删除保护和事务恢复。

#### Scenario: 重复或并行执行

- **WHEN** 多个测试运行或重复运行同一测试
- **THEN** 不依赖其他测试执行顺序或共享配置

#### Scenario: 崩溃恢复

- **WHEN** 进程在持久提交前或后终止
- **THEN** 重建后依据提交标记恢复正确配置并清理恢复记录

### Requirement: 证据范围

验收 MUST 区分模拟 IPC、真实内核、真实用户系统代理和原生界面操作，并完成端到端用户场景。

#### Scenario: 平台验收

- **WHEN** 提交最终验收结果
- **THEN** 模拟测试不能被报告为已通过 Windows 原生用户场景
