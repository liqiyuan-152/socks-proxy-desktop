## Purpose

明确代理生命周期的可观察阶段、健康声明和已应用模式之间的约束，拒绝无效转换并区分准备中的候选会话与已确认会话，使失败时仍可解释实际网络状态。

## ADDED Requirements

### Requirement: 运行时不变量

系统 SHALL 只在会话健康且已确认时声明其已应用模式；无效转换 MUST 保留转换前的有效状态。

#### Scenario: 候选准备

- **WHEN** 新会话已准备但配置尚未持久确认
- **THEN** 快照不提前声明候选模式已经应用

#### Scenario: 候选失败

- **WHEN** 模式切换候选失败而旧会话仍健康
- **THEN** 快照保留旧已应用模式并展示失败

#### Scenario: 无法恢复

- **WHEN** 旧会话无法恢复或进程已经退出
- **THEN** 系统撤回健康声明并提供恢复信息

### Requirement: 转换历史

系统 SHALL 保留有界且脱敏的已接受和拒绝事件历史，供只读诊断导出。

#### Scenario: 超过历史上限

- **WHEN** 转换记录超过保留上限
- **THEN** 仅淘汰最旧记录，不导出会话配置或认证值
