## Purpose

为既有诊断信息增加结构化查看、筛选、聚合和完整原生导出的可验证契约，保留旧文本记录，同时使用错误与追踪身份关联上下文并按既有保留策略自动清理。

## ADDED Requirements

### Requirement: 筛选与完整导出

系统 SHALL 对列表、聚合和导出使用相同的级别、时间和字面文本筛选，导出 MUST 包含全部匹配记录。

#### Scenario: 超过页面上限

- **WHEN** 匹配记录超过界面分页大小
- **THEN** 导出仍包含全部匹配的合法 JSON 行

#### Scenario: 取消保存

- **WHEN** 用户取消原生保存选择器
- **THEN** 不写文件、不显示保存成功

#### Scenario: 字面搜索

- **WHEN** 用户搜索百分号、下划线或 SQL 文本
- **THEN** 查询按字面执行，不将其作为通配符或可执行内容

### Requirement: 身份与保留

诊断 SHALL 保留错误类型、操作及可用的追踪身份和上下文，按既有保留策略自动清理且兼容旧记录。

#### Scenario: 旧记录

- **WHEN** 诊断没有结构化上下文
- **THEN** 仍能查看和导出原摘要

#### Scenario: 重复错误身份

- **WHEN** 同一错误编号被重复记录
- **THEN** 不增加重复记录，同类不同编号仍计入聚合
