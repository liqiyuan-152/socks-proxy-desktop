## Purpose

为现有配置调用者正式记录兼容行为，保留配置 v2 与原有 IPC 数据契约，确保凭据隔离和持久事务边界在服务拆分后继续成立，并支持安全的配置传输。

## ADDED Requirements

### Requirement: 配置兼容

系统 MUST 保持原有配置 v2 文档及既有 IPC 命令参数和返回结构兼容。

#### Scenario: 旧配置加载

- **WHEN** 应用加载有效 v2 配置
- **THEN** 档案、规则、选择和设置保持一致

#### Scenario: 配置导出

- **WHEN** 用户导出配置
- **THEN** 导出可重新导入的配置文档且不包含认证凭据

### Requirement: 持久恢复

系统 SHALL 在修改外部资源前持久保存恢复意图，依据原子提交标记选择恢复方向。

#### Scenario: 未提交中断

- **WHEN** 配置事务未提交时发生进程中断
- **THEN** 重新启动后恢复之前配置

#### Scenario: 已提交中断

- **WHEN** 配置已经提交但清理尚未完成
- **THEN** 重新启动后完成新配置的清理，不回滚已提交凭据
