# Windows 原生桌面稳定性与主动网络恢复

2026-10-04，用户明确允许官方 Tauri WebDriver 后，在 lqy15 交互 Session 3 执行独立 architecture-e2e debug 应用。完整结果为 windows-native-runtime-final.json，汇总和源摘要为 windows-native-runtime-summary.json；测试实际经过生产 WebView、ApplicationService、固定 sing-box 及用户系统代理。

实际持续 1801.555 秒，完成 1262 次通过真实系统代理监听端口的合成 CONNECT/GET 双向探测、59 次规则/全局切换、29 次运行中元数据保存，180 次每十秒左右的页面与进程资源采样。所有样本同一应用 PID 47404、一个健康内核、一个运行目录；元数据保存保持原会话 PID，模式切换使用当前会话端口。期间连续检查页面、底栏和代理名称一致。没有断言失败或中断。

原始工作集、私有内存、句柄和线程样本全部保留。角色合计不比较单个 GPU/辅助进程的生命周期；首尾读数不等价于长期泄漏证明。此范围内没有观察到资源失稳或会话/目录累积，不代表任意持续时长都无泄漏，也不包含应用进程树之外的共享 OS 服务。

结束时从运行中的原生界面进入设置、点击恢复网络并确认，回到状态页确认未运行、未接管、无已应用模式；人工核对 windows-native-network-recovery.png。实际进程检查确认内核为空、运行目录为 0，五个用户系统代理字段的存在性、类型和值与测试前完全相等。最终 UI 清理成功，Node、应用、内核和驱动进程退出，包装器输出 NATIVE_E2E_PASSED。原始代理/PAC 快照仅留远端临时目录，未复制到仓库。

此前同一轮已验证内核退出后的自动网络还原和显式重试；它与本报告的主动恢复共同支持用户确认的恢复语义，但不代表桌面宿主崩溃。由这些完整实际证据，4.5.5 与最终长时间运行稳定性完成。配置导入导出往返及完整 journey 套件仍单独待验收。
