基线源代码从 Git 提交 `0d93dd13359c110b1465f0138b02ccc29ac11bec` 导出至临时目录，仅添加与当前工作区相同的采样测试。两套测试二进制分别构建后，在无构建任务同时运行的条件下交替采样三轮，防止编译负载干扰结果。使用 Debug 构建、磁盘 SQLite 数据库和 10 个无认证代理档案。

每轮配置加载采样 1,000 次，测试宿主初始化与 Tauri 命令分发各采样 100 次；均丢弃预热样本。表中为三轮样本中位数的中位数，单位为微秒。

| -------------------------------------- | ------: | ------: | -----: |
| 配置加载                               |  57.667 |  58.583 | +1.59% |

原始样本汇总见 `phase1-performance.json`。这些数值有调度噪声，不据此推断原生桌面启动或真实内核运行的性能变化：测试宿主初始化不包含原生窗口、托盘、WebView 加载或内核启动，命令分发不包含 JavaScript 到原生 IPC 的完整往返。1.7.4 的完整启动与 IPC 性能验收仍需补充。

可复现采样命令：

```sh

ARCHITECTURE_BENCHMARK_REVISION=working-tree \
cargo test --manifest-path src-tauri/Cargo.toml \
  measure_configuration_and_tauri_dispatch -- --ignored
```
