## Purpose

为状态页和连接日志页提供基于真实运行时的脱敏状态、活跃连接快照和诊断数据，使用户能够区分已应用配置、运行失败与首期不可用的历史连接观测。

## ADDED Requirements

### Requirement: 脱敏活跃连接快照

系统 SHALL 仅从锁定版本的 sing-box 已验证活跃连接接口读取当前连接，包括创建时间、目标、端口、命中规则和出口链。快照记录 MUST 省略密码、认证头、完整 URL 查询参数和其他凭据。该接口不提供已完成连接的成功结果或失败字段；系统 MUST 不将关闭、流量变化或内核文本日志推断为成功或失败事件。接口不可用、认证失败或字段无法验证时，系统 MUST 将观测状态报告为降级，不得生成或展示推测的连接事件或统计数据。

#### Scenario: 读取活跃连接

- **WHEN** 受管内核提供可解析的当前连接元数据
- **THEN** 系统返回可显示的脱敏快照，包含目标、命中规则和出口链，且不声明该连接最终成功

#### Scenario: 历史连接不可用

- **WHEN** 前端请求已完成连接的结果、失败历史或成功率
- **THEN** 系统返回明确的不可用状态，不从内核日志或连接关闭事件生成推测记录

#### Scenario: 活跃连接接口不可用

- **WHEN** sing-box 的已验证活跃连接接口不可用、认证失败或返回无法映射的字段
- **THEN** 系统保留内核运行时、将观测状态标记为降级并记录诊断摘要，而不伪造日志、规则或统计数据

### Requirement: 状态摘要与历史观测降级

系统 SHALL 提供当前活跃连接数量、有限数量的最新活跃连接快照和运行时快照。系统 MUST 将已完成连接总数、成功数、失败数、成功率、失败详情和历史连接分页查询报告为不可用，直到未来变更引入可验证的完成事件接口。

#### Scenario: 获取状态页摘要

- **WHEN** 前端请求运行时状态摘要
- **THEN** 系统返回活跃连接数量、最新活跃连接快照、对应运行时快照和历史观测不可用状态

#### Scenario: 查询连接历史

- **WHEN** 前端以任意过滤条件和游标请求连接日志
- **THEN** 系统返回明确的不可用状态，不返回伪造的事件页、游标或匹配总数

### Requirement: 活跃连接详情与诊断清理

系统 SHALL 为单条活跃连接快照提供脱敏详情，供前端展示和复制。系统 MUST 允许在用户确认后按时间范围清理运行时诊断记录；清理诊断不得改变当前活跃连接快照。

#### Scenario: 复制活跃连接详情

- **WHEN** 用户请求复制一条活跃连接快照详情
- **THEN** 系统返回仅含脱敏字段的可复制文本，且不包含密码、认证头、完整 URL 查询参数或内部路径

#### Scenario: 清理运行时诊断

- **WHEN** 用户确认清理当前时间范围匹配的运行时诊断
- **THEN** 系统仅删除匹配诊断、返回删除数量并更新后续诊断查询，同时不改变当前活跃连接快照

### Requirement: 运行时诊断事件

系统 SHALL 记录内核启动、模式提交、回滚、停止和异常退出等状态转换，并向前端推送或提供可轮询的最新快照。诊断记录 MUST 包含关联时间和可显示摘要，且不得被呈现为连接成功或失败事件。

#### Scenario: 模式切换失败

- **WHEN** 模式切换未能提交
- **THEN** 系统记录失败与回滚结果，并使前端能够取得未伪装为成功的当前快照
