## Purpose

提供可选择的国内直连策略，让命中中国域名集的域名与命中中国地址集的字面 IP 直连、其他目标使用默认代理，并清楚说明规则集及覆盖范围的限制，而不是宣称识别网络封锁状态。

## ADDED Requirements

### Requirement: 可选国内直连预设的优先级
系统 SHALL 仅在规则代理模式且用户开启预设时，按用户自定义规则、中国域名规则集（仅域名）、私有/局域网地址及中国 IPv4/IPv6 地址规则集（仅入口字面 IP）、默认代理的顺序决策。用户规则可显式覆盖预设；预设开启要求有效默认代理。对预设无法识别为国内的目标 MUST 选择默认代理，不得依据名称或域名解析候选地址将其臆断为可直连。

#### Scenario: 国内 IP 与海外 IP
- **WHEN** 预设开启且目标分别为命中中国地址集的 IP 与未命中的公网 IP
- **THEN** 前者直连，后者走默认代理

#### Scenario: 用户规则覆盖预设
- **WHEN** 用户规则把一个命中中国域名集的站点指定到代理 B
- **THEN** 该站点使用 B，而不被后续预设改为直连

#### Scenario: 未配置默认代理
- **WHEN** 用户开启预设但没有有效默认代理
- **THEN** 配置被拒绝，先前预设与运行时保持不变

### Requirement: 域名与字面地址的判断边界
系统 SHALL 仅对入口目标为字面 IPv4/IPv6 地址的连接应用私有/局域网及中国 IP 地址预设；同时未命中用户规则和中国域名集的域名 MUST 使用默认代理，而不依据其 DNS 解析结果改为直连。解析失败、重试或地址族回退 MUST 不让此类域名降级直连；代理服务器自身及内核内部连接 MUST 不递归进入本地代理入口。系统 SHALL 说明未接管的应用 DNS 请求不在保障范围内。

#### Scenario: 域名集外但解析到国内地址
- **WHEN** 预设开启、域名未命中用户规则及中国域名集，即使其解析结果全部属于中国 IP 集
- **THEN** 选择默认代理，不声称对此域名进行了 IP 归属分流

#### Scenario: 混合国内外解析地址
- **WHEN** 未命中域名规则的域名同时解析出中国和非中国的 A/AAAA 地址
- **THEN** 该域名仍选择默认代理，不因任一候选地址属于中国而直连

#### Scenario: 重试或地址族回退
- **WHEN** 一次连接重试或在 IPv4/IPv6 之间回退并更换目标 IP
- **THEN** 域名集外的域名保持默认代理出口，不根据新解析地址切换为直连

#### Scenario: 解析失败
- **WHEN** 预设开启、域名集外的域名在后续连接时解析失败
- **THEN** 不将此目标默认直连，显示默认代理的路由选择，连接失败另行报告而不伪称成功

#### Scenario: 字面 IPv6 地址
- **WHEN** 入口目标是命中中国 IPv6 地址集的字面 IP，且无优先用户规则
- **THEN** 选择直连；未命中的字面公网 IPv6 地址选择默认代理

### Requirement: 规则集可信度与离线行为
系统 SHALL 为中国域名和 IP 数据指定版本、来源、校验方式与离线可用版本，并在应用更新时保证数据与所使用内核兼容。缺失、损坏或不兼容的规则集 MUST 阻止开启预设或提交依赖预设的运行时修订；不得把空规则集当作成功加载。界面 SHALL 将其描述为“国内直连”，说明地理归属不等于 GFW 可达性。

#### Scenario: 离线启动
- **WHEN** 用户离线启动且受校验的本地规则集可用
- **THEN** 国内直连预设仍可工作，无需启动时获取远程数据

#### Scenario: 规则集无效
- **WHEN** 本地规则集校验失败
- **THEN** 新配置不被提交，保留原运行时并报告明确错误

### Requirement: 规则命中测试
系统 SHALL 提供输入目标域名或字面 IP 及端口的测试，返回命中的用户规则或预设阶段、可确定的动作与出口及规则集不可用等错误。测试结果 MUST 与同一配置的实际决策语义一致；不得把所选出口伪称实际拨号地址或连接成功结果。测试无需实时 DNS 解析；规则集依赖不可用时 MUST 报错，而不得伪称已确定命中结果。

#### Scenario: 测试自定义规则
- **WHEN** 用户输入一个与显式代理规则匹配的域名和端口
- **THEN** 显示该规则的名称与所选代理，并说明不需要后续预设判断

#### Scenario: 域名集外测试
- **WHEN** 测试一个未命中中国域名集及用户规则的域名
- **THEN** 显示选择默认代理及域名集外不按解析 IP 判断的原因，不声称已观察到真实连接结果

#### Scenario: 规则集不可用
- **WHEN** 开启预设且测试依赖的本地规则集缺失或损坏
- **THEN** 返回规则集错误，不虚构直连或默认代理测试结果
